# Four Quadrant Review (四象限法 - 周复盘 - 人生主线)

Web + WeChat Mini Program for personal weekly review and life planning.

## Project structure

```
four-quadrant-review/
├── shared/          # Shared core (data models, business logic)
├── web/             # Web version (HTML/CSS/JS)
├── miniprogram/     # WeChat Mini Program version (WXML/WXSS/JS)
└── README.md
```

## Quick start

### Web (local)
```bash
cd web
python -m http.server 8080
# Open http://localhost:8080
```

### Mini Program
1. Open WeChat DevTools
2. Import the `miniprogram/` directory
3. Compile and preview
